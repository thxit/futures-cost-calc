# 期货品种生产成本计算器

一键计算各期货品种的生产成本，辅助判断当前价格是否处于盈亏区间。

## 品种覆盖

- **黑色系**: 螺纹钢、热卷、焦炭、铁矿石
- **农产品**: 豆粕、豆油、大豆、白糖、生猪、鸡蛋、玉米、棉花
- **化工品**: PTA、甲醇、PP、PVC、纯碱、玻璃、尿素
- **有色金属**: 沪铝、沪铜
- **能源化工**: 燃料油、沥青、液化石油气

## 使用方法

1. 左侧选择品种
2. 输入当前原料价格（默认值可修改）
3. 点击「计算生产成本」
4. 输入当前期货价格，点击「对比」看盈亏

## 运行

- 双击 `启动计算器.bat` 启动
- 或命令行 `python main.py`
